# נועמייקר 🧡 – הסדנה של נועם

האתר של העסק הראשון של נועם: חנות למוצרים בהדפסת תלת־ממד, עם משלוח עד הבית בקיבוץ.
ההזמנות נשלחות לנועם בוואטסאפ, והתשלום בפייבוקס יאנג.

## הפעלה ראשונה

```bash
npm install
npm run dev            # האתר רץ על http://localhost:5173
```

לבניית גרסה להעלאה: `npm run build` (התוצאה בתיקייה `dist/`, אפשר להעלות ל-Netlify / Vercel / Cloudflare Pages).

## מבנה

| מה | איפה |
|---|---|
| טקסטים ומבנה הדף (גיבור, סיפור, 4 שלבים, חנות) | `index.html` |
| מספר וואטסאפ, אמצעי תשלום, קטגוריות | `src/config.js` |
| לוגיקה: קטלוג, סל, שליחה לוואטסאפ, אנימציות GSAP | `src/main.js` |
| עיצוב | `src/style.css` |
| מוצרים (נוצר אוטומטית מהמלאי) | `src/products.json` |
| לוגו, דמויות, סרטון | `public/assets/` |
| רשימת פרומפטים לתמונות מוצר | `docs/product-photo-prompts.md` / `.csv` |

## עדכון מוצרים מהמלאי

1. מעתיקים את `מלאי_חנות_3D.xlsx` המעודכן ל-`scripts/inventory.xlsx`
2. `npm run products`

רק שורות עם סטטוס **מוכן למכירה** עולות לאתר. מחיר = "מחיר לצרכן כולל מע״מ".

תמחור (בגיליון "הגדרות"): העלות מבוססת בעיקר על החומר (גרם × מחיר פילמנט + 10% כשלים) + חשמל 0.2 ₪ לשעה + אריזה, × מכפיל 3 + מע״מ.
אם בעמודה "מחיר שוק (₪, ידני)" יש ערך, והמחיר לפי הנוסחה סוטה ממנו ביותר מ-20% – נקבע מחיר השוק.
הקטגוריות במלאי ממופות לקטגוריות החנות בראש `scripts/build-products.py`.

## תמונות מוצר

שומרים תמונה בשם המק״ט ב-`public/assets/products/` (למשל `ORG-001.webp`, או `.jpg`/`.png`) ומריצים `npm run products`.
מוצר בלי תמונה מוצג עם איור הקטגוריה ו"תמונה בקרוב".
הכי טוב: לצלם את ההדפסות האמיתיות של נועם – הלקוח רואה בדיוק מה יקבל.

## צבעי התמונות

הפרומפטים ב-`docs/product-photo-prompts.csv` שומרים כרגע על הצבעים המקוריים של כל דגם, לפי תמונת הרפרנס שלו (`3D store\images`).
כדי להתאים לצבעי הפילמנט במלאי: ממלאים `scripts/colors.csv` (`sku,color`) ומריצים `npm run photo-prompts`.

## רישיונות

רוב הדגמים באים מ-MakerWorld עם רישיון לשימוש אישי. למכירת הדפסות צריך רישיון מסחרי מהמעצב של כל דגם –
העמודה "רישיון מסחרי נדרש" ב-`docs/product-photo-prompts.csv` מסמנת אילו.

## פרטיות

לאתר יש `noindex` כדי שלא יופיע בגוגל – הוא מיועד לשיתוף בקבוצות הקיבוץ.
